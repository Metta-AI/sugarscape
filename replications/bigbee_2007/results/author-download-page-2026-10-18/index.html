MASON Sugarscape

 

Full Package

MASON 12 and Release 1.1.2  11/25/2007  [9.4 MB .tar.gz]

The package includes extensive documentation, all source code, all MASON classes, all external libraries.  Start with the README.  It also contains ideas for student projects and research projects.

A Java-based  open source replication of the classic model created by J. Epstein and R. Axtell and described in Growing Artificial Societies (1996).    Implemented using GMU’s MASON agent-based simulation toolkit.  Most, but not all, of the Sugarscape rules are implemented.
