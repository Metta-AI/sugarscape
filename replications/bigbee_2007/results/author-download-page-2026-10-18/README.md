# Author download page recovered from December 2008

The [archived author page](https://web.archive.org/web/20081223024825/http://web.mac.com:80/tony.bigbee/mason_sugarscape/MASON_Sugarscape.html) identifies release 1.1.2 with MASON 12 and dates it November 25, 2007. This is earlier evidence than the 2011 Google Code upload metadata. It corroborates that the recovered release's framework pairing was intentional, rather than proving a later accidental library substitution.

The HTML also contains links naming versions 1 and 1.1.1, alongside a dynamic file-sharing link and the former Java.net project. These are source-recovery leads, not recovered implementations. Exact-URL Wayback availability queries returned no snapshots for the three package URLs or either protocol of the Java.net root. No broader absence claim follows.

The paper describes MASON 10. This page therefore narrows the historical discrepancy without closing it. No earlier package bytes, experimental seed list, or paper-specific source revision was recovered. Existing native and corrected model runs remain unchanged and the study remains incomplete.

The original HTML, response headers, page hash, parsed links, and availability responses are retained. The snapshot date is December 23, 2008; the November 2007 date is a claim displayed on that page. These dates are not interchangeable.
