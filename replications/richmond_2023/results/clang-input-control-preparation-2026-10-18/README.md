# Paired native initialization control

The released initial illustration matches all 65,536 Clang/libc++ capacity
classes, while GNU/libstdc++ differs. We separately replay the two complete
initial states through the original native JSON input interface, with unchanged
GPU functions and the previously qualified passive observer. No seed or image
comparison parameter is fitted.

The source prefix containing all GPU functions and the exit condition is byte
identical between the image-introduction commit and the released benchmark.
The engine versions differ, so this control does not establish historical
visualization equivalence. It isolates initialization under the released engine.

Both runs use seed zero, width 256, occupation 0.17 and all 100 original steps.
Before interpreting Clang, GNU input replay must match the original initializer's
complete population and active-state trajectories. Native initial active states
must match their supplied data. The existing fixed image grid, palette and
orientation remain unchanged.

The owned H100 command has a 15-minute bound, 300 seconds per native run, and a
100 MiB collection cap. Its initial registration lacked the required detached
flag and was rejected before execution; that rejection is retained. The accepted
command is `cmd-n4fh7`. At preparation time the existing node was restoring and
no simulation result was claimed. Neither this control nor its input dataset
adds a completed-study count.
