Use one serial worker on a dedicated CPU node. Run three PhaseI approaches, threshold-ten explicit/network models with and without movement policy, and both common-resource models: nine configurations total. Use 100 NumPy/module seeds (0–99), Mesa seed42, 1000steps, Python3.11.14, Mesa0.8.5, NumPy1.26.4, SciPy1.16.3 and NetworkX3.6.1. Preserve original source pins and PYTHONHASHSEED=0.

Before the ensemble, execute nine seed1001 controls with both the existing observer and the timing runner. Require byte-identical initial agents, prices, population and health outputs in every pair. These controls are not ensemble replicates. Stage unchanged run_groups.py beside each frozen runner named run.py to reuse validated threshold/policy parameterization; do not modify the native engines.

For each seed block, shuffle all nine configurations using a separate Python Random(20261017) scheduler. Never draw the scheduler's random numbers inside a simulation. Write the complete order and all source hashes before execution. Record every command, exit status and output hash. One simulation at a time; no concurrent task-owned workloads on this node. Limit each run to300seconds and the full workflow to12hours. Stop below4GiB free space without deleting evidence or replacing failed seeds.

Retain the native1000 timing rows, stdout and all four parity outputs. The author's timer ends before data collection; PhaseI explicit/network reassessment also occurs outside that timer. Native prints remain unchanged and stdout goes to an ordinary retained file for every configuration.

After complete coverage, report seed-paired mean differences and ratios with pointwise95% intervals. Compare PhaseI explicit/network versus standard, group-policy explicit versus network, and common-resource multilevel versus one-level. Distinguish relative timing on this environment from historical seconds; hardware/software versions differ. Native common-resource nonfinite states remain numerical failures, even if timings are complete. Keep these failures visible in interpretation. No timing finding alone establishes paper replication.
